## Fixes from a review of all the code

### Storia Cluster

- **No more lost writes when the relay cannot store them.** Writes kept on a worker while the relay was away used to
  be thrown away if the relay then answered with an error (a full disk, for example). They are now kept, together
  with everything after them, and sent again every few seconds. A write the relay still refuses after 10 minutes
  is moved to `cluster-spool/failed/` instead of being deleted.
- **Scoreboard changes wait for the relay.** Changes made while the relay was away were dropped, so workers could
  disagree. They now wait, in order, and reach the other workers once the relay is back.
- **Time and weather reports no longer pile up.** One report at a time instead of a new thread every second while
  the relay is slow.
- **Contraption links respect the hand-over pause.** A cell that another worker had just let go of is no longer handed
  over right away when a contraption link is found, so that worker's last saves are never refused.

### Storia Relay

- A connection that never says who it is is closed after 10 seconds.
- On stop (console, Ctrl+C or systemd), the world files are written out to disk before the process ends.

### Other

- Clearer error messages for invalid namespaces and channels in the plugin API.

Tested: relay outage with 638 waiting writes, a relay that refuses writes until fixed (no write lost), two workers
with bots (moves, merging, balancing, `/stop`), scoreboard, time and weather, game rules, shared plugin data
(400 of 400 concurrent increments), duplicate node names, and a single server.
