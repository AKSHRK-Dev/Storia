## What is new since 26.2-10

Storia for **Minecraft 26.3**, based on Folia `ver/26.3.x`. Every Storia feature from 26.2-10 is carried over. When
upgrading a Storia Cluster, update Storia Relay, every worker and Storia Proxy together. No setting has to change.

- **Minecraft 26.3** (Folia and Paper 26.3). Requires Java 25, as before.
- **Seamless moves for 26.3 clients**: Storia Proxy now switches 26.3 players between workers without a loading
  screen too (26.1, 26.2 and 26.3 clients).
- **Linear region format**: Minecraft 26.3 no longer ships the Zstandard library, so Storia now includes it.
- **World generation**: Paper 26.3 now has its own faster noise sampling and block counting, so Storia's earlier
  worldgen patch was retired. Terrain is unchanged and still identical to vanilla.

Tested before this release: a single server (start, stop, RAM world, `/storia` commands); pregeneration in Anvil and
Linear, then a restart that reads the Linear regions back; a Storia Relay with a worker (join, pregeneration stored on
the relay, clean leave).

All release notes: https://storiamc.com/en-us/releases/
