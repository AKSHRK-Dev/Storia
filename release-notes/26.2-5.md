## Storia's own bStats pages

Storia and Storia Proxy now report their anonymous statistics to their own bStats pages instead of Folia's and
Velocity's:

- Storia (servers and workers): https://bstats.org/plugin/bukkit/Storia/34364
- Storia Proxy: https://bstats.org/plugin/velocity/StoriaProxy/34365

What is sent every 30 minutes: server and player counts, the Storia, Minecraft and Java versions, OS and CPU core
count, whether the server is a single server or a cluster worker, and whether the RAM world is on. No player names,
IP addresses, chat or world data. Storia Relay sends nothing.

To turn it off, set `enabled: false` in `plugins/bStats/config.yml` (servers) or `enabled=false` in
`plugins/bStats/config.txt` (Storia Proxy), as before.

What Storia does with your data, how it behaves for players and how it compares with vanilla:
https://storiamc.com/en-us/docs/safety/
