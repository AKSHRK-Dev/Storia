## New: Linear region format

Worlds can now be stored in the [Linear region format](https://github.com/xymb-endcrystalme/LinearRegionFileFormatTools):
each region is one Zstandard-compressed `r.X.Z.linear` file instead of an `.mca` file with every chunk compressed on
its own. Set `region-format.type: linear` in `storia.yml`.

- **About half the disk space**: 12 overworld regions went from 46.1 MB (Anvil) to 25.5 MB at compression level 1
  and 21.4 MB at level 6. The End shrinks much more.
- **Existing worlds just work**: a region is read from its `.mca` the first time it is used and written as `.linear`
  from then on. The `.mca` files are left in place until you delete them.
- **Compatible with the Linear tools**: Storia reads files made by `convert_region_files.py mca2linear`, and the tools
  read the files Storia writes (checked with the tools' own reader).
- Works with the RAM world (smaller files, less RAM).
- Safety: an unreadable `.linear` file is never overwritten, and Storia refuses to start on `anvil` if the world has
  `.linear` files, so it never runs on outdated `.mca` copies.
- Changed regions are written every `flush-seconds` (5 by default), on `save-all flush` and on stop.

Guide: https://storiamc.com/en-us/docs/linear/
