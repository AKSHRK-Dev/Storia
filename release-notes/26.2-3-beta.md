## Storia Worker is now a Storia Cluster server

Storia Worker used to compute only the terrain noise of new chunks for one server. It is now one server of a
**Storia Cluster**: each worker runs the part of the shared world where its players are, and players move between
workers through Storia Proxy without a loading screen. Add workers when your players outgrow one machine.

- **No world copy for new workers**: on first start a worker fetches the world settings (level.dat, world
  generation settings, data packs) from Storia Relay. Set `cluster.coordinator`, `cluster.node-name` and
  `cluster.secret` in the worker's `storia.yml`, and add it to the proxy's `velocity.toml`.
- **Storia Relay is the cluster's coordinator** and nothing else. A server that still asks it for terrain
  offload is refused with a message saying the feature was removed.
- **Terrain-only offload was removed** (`offload.*` in `storia.yml`, `-Dstoria.worker=true`, `/storia offload`).
  An old `offload:` section in `storia.yml` is ignored. The code is kept in the `archive/terrain-offload` branch.

## Also in this release

- Players are never moved twice while Storia Proxy is still switching them to another worker.
- The border guard and its "Another Storia server runs the area ahead" message were removed; areas merge onto one
  worker long before anyone reaches a border.
- Checked with a real Minecraft 26.2 client: moves by balancing, by flying into another worker's area and by
  `/stop` keep the connection and the world on screen.

Guide: https://storiamc.com/en-us/docs/cluster/ · Worker setup: https://storiamc.com/en-us/docs/worker/

**Beta:** back up your world before trying it. Seamless moves need Minecraft 26.1/26.2 clients.
