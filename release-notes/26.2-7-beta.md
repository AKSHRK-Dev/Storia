## Faster and lighter Storia Cluster

- **Chunks are no longer compressed twice.** Chunk records, player data and data files are already compressed, but
  the encrypted link deflated them again: no smaller (100.1%), just CPU on both ends. They are now sent as they are.
  Measured with one worker pregenerating 2,601 new chunks: **Storia Relay used 23% less CPU** (18.6 s down to
  14.4 s, two runs each). Other messages are still compressed. The wire format is unchanged.
- **The relay remembers where players were**, also after a restart (`storia-cluster-positions.txt` in the cluster
  world), so a returning player still joins the worker that runs their area.
- Link reports and move confirmations use a small shared pool instead of a new thread each time.

Tested: two workers with bots (moves, merging, balancing, `/stop`), a relay that refuses writes until fixed (no write
lost), shared plugin data (400 of 400), positions loaded again after a relay restart.
